Yangi alifbo klaviaturasi

Odatdagidek eski usulda yozing, harflar yozayotganingizda yangi alifboga özi ögiriladi. Masalan, Sherzod deb yozsangiz, Şerzod çiqadi.

sh→ş ch→ç o'→ö g'→ğ

Yoziş

Harf qöşiş: 0 belgi

Sinab köring:

Eski yozuvdagi matnni joylasangiz (Ctrl+V), u ham darhol ögiriladi, undagi email va havolalar esa özgarmaydi. Email yoki havolani qöldan yozayotganda «Avtomatik ögiriş»ni öçirib turing.

Apostrofning qaysi şaklini işlatsangiz ham (' ‘ ’ ʻ ` va boşqalar), o' darhol ö ga, g' esa ğ ga ögiriladi.

2 ta tugma bilan: AltGr + S → ş, AltGr + C → ç, AltGr + O → ö, AltGr + G → ğ. Caps Lock yoniq bölsa, xuddi şu tugmalar Ş Ç Ö Ğ beradi. AltGr — öng Alt tugmasi, Mac'da Option.

Yangi alifboda 28 ta harf va 1 ta tutuq belgisi (ʼ) bor. «ng» alohida harf hisoblanmaydi, lekin yozuvda özgarmaydi: dengiz → dengiz.

Windows, Keyman'siz: klaviaturangiz özgarmaydi

  1. autohotkey.com saytidan AutoHotkey v2'ni örnating (bepul).
  2. YangiAlifbo-Windows.zipni yuklab oling, öng tugma → «Extract All», çiqqan papkani Documents'ga köçiring.
  3. YangiAlifbo.ahkni ikki marta bosing. Soat yonida kök Ş belgisi çiqadi. Ctrl + Alt + Space bilan yoqiladi va öçiriladi.

Keyman orqali: kompyuter (Windows, macOS, Linux) va telefon uçun «Yangi Özbek Lotin» klaviaturasi.

Klaviaturani yuklab oliş Keyman dasturi yangi_ozbek.kmp · 10 KB

Windows, macOS, Linux

  1. keyman.com saytidan Keyman'ni örnating.
  2. yangi_ozbek.kmp faylini ikki marta bosing va «Install»ni tanlang.
  3. Windows'da klaviaturani Win + Space bilan almaştiring.

Android

  1. Play Market'dan «Keyman» ilovasini örnating va uni tizim klaviaturasi sifatida yoqing (ilova özi körsatadi).
  2. Keyman'da: Settings → Install Keyboard or Dictionary → Install from local file → yangi_ozbek.kmp.
  3. Yozayotganda globus tugmasi bilan «Yangi Özbek Lotin»ni tanlang.

iPhone, iPad

  1. App Store'dan «Keyman» ilovasini örnating.
  2. yangi_ozbek.kmp faylini Fayllar ilovasida oçing → Ulaşiş → Keyman.
  3. Sozlamalar → Umumiy → Klaviatura → Klaviaturalar → Keyman'ni qöşing.

Kompyuterda: AltGr + S C O G bilan ş ç ö ğ darhol çiqadi, Caps Lock yoniq bölsa Ş Ç Ö Ğ. Ögirmasdan «sh» kerak bölsa (email, havola): s, keyin AltGr + H.

Telefonda: yuqori qatorda Ö Ğ Ş Ç tugmalari bor. Ögirmasdan «sh» kerak bölsa, s tugmasini bosib turing va «sh»ni tanlang.
