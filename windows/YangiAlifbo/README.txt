YANGI ALIFBO — Windows uçun (Keyman'siz)
=========================================

Klaviaturangiz, uning tili va körinişi özgarmaydi. Odatdagidek eski usulda
yozasiz, matn yangi (2026) özbek alifbosiga özi ögiriladi:

    sh → ş     ch → ç     o' → ö     g' → ğ     ma'no → maʼno
    o' ning barça şakllari ögiriladi: o'  o`  o‘  o’  oʻ

    AltGr (öng Alt) + S / C / O / G   →   ş ç ö ğ
    Caps Lock yoniq bölsa             →   Ş Ç Ö Ğ

Word, Telegram, brauzer va boşqa har qanday dasturda işlaydi.


ÖRNATIŞ
-------
1. https://www.autohotkey.com saytida "Download v2.0" tugmasini bosib,
   AutoHotkey'ni örnating (bepul, bir marta).
2. YangiAlifbo-Windows.zip faylini öng tugma bilan bosing → "Extract All"
   (Hammasini çiqarib oliş). Çiqqan YangiAlifbo papkasini, masalan,
   Documents (Hujjatlar) papkasiga köçiring.
3. Papka içidagi YangiAlifbo.ahk faylini ikki marta bosing. Soat yonida
   kök Ş belgisi paydo böladi. Birinçi marta "Kompyuter yoqilganda
   avtomatik işga tuşsinmi?" deb söraydi — "Yes" (Ha) ni bosing.


BOŞQARIŞ
--------
- Ctrl + Alt + Space — yoqiş / öçiriş. Belgi kulrang bölsa — öçiq.
- Soat yonidagi Ş belgisini öng tugma bilan bosing: yoqiş/öçiriş,
  avtomatik işga tuşiş, yordam, çiqiş.
- Ögirmasdan "sh" kerak bölsa (email, havola): s, keyin AltGr + H.


DIQQAT
------
Parolingizda sh, ch yoki o' bölsa, parol yozişdan oldin Ctrl + Alt + Space
bilan öçirib turing, aks holda parol ham ögirilib ketadi.
