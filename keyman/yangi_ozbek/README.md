Yangi Özbek Lotin keyboard
==========================

Description
-----------
Eski lotin yozuvida yozing, matn yangi (2026) özbek alifbosida çiqadi:
sh → ş, ch → ç, o' → ö, g' → ğ, harf + ' → ʼ.

Type Uzbek the old way and get the new (2026) Uzbek Latin alphabet.
