Yangi Özbek Lotin

Eski lotin yozuvida qanday yozgan bölsangiz, şunday yozavering. Klaviatura harflarni yangi (2026) alifboga özi ögiradi.

Siz yozasizÇiqadiMisol
s hşSherzod → Şerzod
c hçchoy → çoy
o 'öO'zbekiston → Özbekiston
g 'ğtog' → toğ
harf + 'ʼma'no → maʼno

Apostrof örniga ` belgisini işlatsangiz ham böladi: o`zbek → özbek.

Kompyuterda

  • AltGr (öng Alt) + S / C / O / G → ş / ç / ö / ğ. Shift qöşsangiz, boş harf çiqadi: Ş Ç Ö Ğ.
  • Ögirmasdan «sh» yoki «ch» kerak bölsa (masalan, email manzil): s, keyin AltGr + H.
  • Oddiy apostrof: AltGr + '.
